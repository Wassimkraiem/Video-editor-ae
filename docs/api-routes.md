# API routes

The FastAPI app exposes the documented route families under `/api/v1`: auth,
projects and timeline versions, streamed assets and transcripts, agent runs and
SSE events, renders and SSE events, compositions, skills and script approvals,
style extraction jobs, generated images, health, readiness, and signed media.

OpenAPI is generated by FastAPI at `/docs` and `/openapi.json`. A production
build exports that schema into `packages/api-client` for the web client.
