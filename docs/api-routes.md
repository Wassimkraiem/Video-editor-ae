# API routes

The FastAPI app exposes the documented route families under `/api/v1`: auth,
projects and timeline versions, streamed assets and transcripts, agent runs and
SSE events, renders and SSE events, compositions, skills and script approvals,
style extraction jobs, generated images, health, readiness, and signed media.

OpenAPI is generated by FastAPI at `/docs` and `/openapi.json`. A production
build exports that schema into `packages/api-client` for the web client.

## Studio routes

| Route | Purpose |
| --- | --- |
| `GET /projects/{id}/assets` | Uploaded media with ingest status and probe summary |
| `GET /projects/{id}/events` | SSE: `asset.uploaded`, `ingest.started/completed/failed` |
| `GET /projects/{id}/outputs` | MP4s in `renders/` and `compositions/`, with signed URLs |
| `GET`/`PUT /projects/{id}/memory` | The project's `CLAUDE.md` |
| `GET /projects/{id}/storyboard` | `storyboard.json` for planned runs |
| `GET /projects/{id}/runs`, `/renders` | History, newest first |
| `POST /projects/{id}/runs` | `{brief, skill?}`; `skill` names a style such as `wassim-style` |
| `POST /runs/{id}/messages` | Approve a storyboard, or send a follow-up that resumes the SDK session |
| `GET /runs/{id}/events` | SSE: `run.created`, `agent.message` (raw SDK message with `_type`), `agent.succeeded/failed`, `user.answer` |
| `GET /project-files/{project}/{path}` | Signed or owner-only access to `renders/`, `compositions/`, `proxies/` |

SSE streams replay from `Last-Event-ID` and stay open with heartbeats until
the client disconnects. `GET /readyz` reports `worker` (`local` when jobs run
inside the API) and `agent_key_configured`.
