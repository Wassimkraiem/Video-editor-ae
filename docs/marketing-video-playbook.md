# Marketing video playbook

Research notes behind the marketing-format styles in `skills/library/` (October 2026).
What big brands and top-performing app marketers do, reduced to formats we can generate.
We copy **formats, structures and techniques**, never anyone's footage, music, logos or
exact designs.

## What every platform rewards

- **The first 1-3 seconds decide the ad.** Lead with the viewer's problem or a bold claim,
  not the logo. Spoken hooks in the first 2 s beat visual-only hooks. No slow brand intros.
- **Native vertical beats resized commercials.** Build 9:16 (1080x1920) first; 4:5 and 16:9
  are cutdowns.
- **Sound-off first, sound-on bonus.** Most Reels play muted: captions and on-screen text
  must carry the message; music and SFX add energy when heard.
- **Safe zones (Reels/TikTok UI):** keep text out of the top ~250 px and the bottom ~320 px
  of a 1080x1920 frame; avoid the right ~120 px edge (action buttons).
- **Length:** ads 6-30 s (15-20 s sweet spot on Reels), launch/promo 30-60 s, demos 60-90 s.
- **One feature solving one problem** outperforms a general overview.
- **Show the real product within ~5-10 s.** Viewers should know what it does by second 8.
- **Volume and variants:** 3-4 alternate hooks on the same body; 30/15/6 s cutdowns.

## Formats (and the style that makes each)

| Format | Structure | Length | Style |
|---|---|---|---|
| Performance ad | Hook -> Problem -> Solution demo -> Proof -> CTA | 15-30 s | `performance-ad` |
| Voiceover-free product cut | Intro -> feature at work -> use cases -> outro, music + on-screen text, real UI | 30-60 s | `ui-feature-reel` |
| Three-step workflow pre-roll | Hook (5 s) -> "Step. Step. Step." demo (10 s) -> outro (5 s), bold type | 15-20 s | `three-step-promo` |
| Kinetic type recap | Rationed words, one idea per shot, cuts on the beat, product between words | 20-60 s | `kinetic-type-recap` |
| Teaser / countdown | Dark, rim-lit fragments, typed text, cropped UI, waitlist CTA | 10-40 s | `teaser-countdown` |
| Offer / sale ad | Hook with the deal -> what you get -> price card -> urgency -> CTA button | 10-20 s | `offer-ad` |
| Social proof | Real person + result, quote cards, stars, logo row, lower-third name | 15-45 s | `testimonial-proof` |
| Listicle / explainer | Numbered points, one visual per point, progress bar, recap | 20-60 s | `listicle-explainer` |

Formats already covered by existing styles: product launch types (teaser, UI hero reveal,
feature drop, before/after, problem-solution, integration, milestone...) in
`product-launch-motion`; editorial kinetic captions in `kinetic-editorial-reel`; any custom
look in `auto-style`.

## Techniques worth copying

- **Real UI, simplified:** recreate the product's screens as clean cards (dark mode, big type,
  one highlighted element), not blurry screen recordings.
- **Restraint (Apple-style recaps):** most frames are product, words are rationed, type sits at
  roughly 6-7% of frame height in the brand's own sans, and shot changes land on the music beat
  (median shot ~1.9 s at 30 fps).
- **Motion matches the product's value:** fast and snappy for speed products, slow and smooth
  for premium.
- **Soft depth, not spectacle:** glass cards, gentle 3D tilts of UI panels, gradient glows;
  gratuitous 3D looks dated.
- **Contrast keeps attention:** alternate light/dark, text/graphic, close/wide, and one live or
  photographic moment inside UI animation.
- **Prove each claim within seconds:** feature -> use case -> feature -> use case.
- **End on one action:** one CTA line, one button, optional logo; no stacked CTAs.
